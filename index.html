「止まらない堅牢性」×「最先端AI」の融合

エンタープライズ規模の業務自動化（RPA / VBA）で培った「エラーで絶対に止めない厳格な例外設計思想」をベースに、現在は生成AI・自律型エージェントを活用した開発プロセスの標準化を推進しています。

開発ライフサイクル全域を標準化する「AI駆動開発基盤」の策定・PoC

要件定義・設計・実装・テスト・運用保守・エラー相談の全工程に対応する特化型AIエージェント群を設計。SharePointでテンプレートを一元管理し、ローカル環境でセキュアに動かす運用を一人で推進。

📍
⚡ 数時間作業 → 約1分に短縮
Node.js Puppeteer Gemini 3.1 Pro Notion API

Google Maps × 生成AIによるSNSコンテンツ量産・DB構築システム

Google Mapsの動的スクレイピングからGemini（Google検索連携）によるハルシネーション抑制台本生成、NotionへのUpsert格納までを一気通貫で自動化。維持費ほぼゼロの量産体制を確立。

🕸️
⚡ 複数サイト自律巡回・抽出
OpenClaw Local Gateway Gemini 3.1 Pro 自律型AI

OpenClawを用いた自律型AIエージェント環境構築

OSSの『OpenClaw』を用いてローカルゲートウェイ（port: 18789）を構築。gemini-3.1-pro-previewを統合し、複数サイトを自律巡回してライブ情報やチケット情報を抽出・一覧化するボット基盤を開発。

⚡ 月数百時間削減 / エラー率0%
UiPath Excel VBA RPA 堅牢性設計
