# 前田 辰之介 | ポートフォリオ Webサイト

AI駆動開発（AIDD）、自律型AIエージェント構築、エンタープライズ業務自動化を推進するエンジニアとしてのポートフォリオサイトです。
Notionドキュメントと連携しており、Webサイト側は「ハイライト・看板」、Notion側は「詳細ドキュメントのマスター」として二重管理を防ぐ設計になっています。

---

## 🚀 サイトの見方・動かし方

### 方法 1: ダブルクリックで開く（一番簡単！）
1. デスクトップの **「自己紹介」** フォルダを開きます。
2. その中にある **`index.html`** をダブルクリックしてください。
3. お使いの標準ブラウザ（Google Chrome、Safari等）でウェブサイトが表示されます。

### 方法 2: ターミナルから開く
Macのターミナルで以下のコマンドを実行してもブラウザで直接起動できます：
```bash
open ~/Desktop/自己紹介/index.html
```

## 🎨 自分好みにカスタマイズする方法

テキストエディタ（VS Code、テキストエディット、Cursorなど）で `index.html` や `style.css` を開いて編集できます。

### 1. 写真やイラストの差し替え
`index.html` の `hero-visual` 内にあるアバター部分は、現在SVGアイコンが表示されています。
ご自身の写真を表示したい場合は、フォルダ内に画像を保存し（例: `profile.jpg`）、以下のように書き換えてください：

```html
<!-- 変更前 -->
<div class="avatar-placeholder">
  <svg ...>...</svg>
</div>

<!-- 変更後 -->
<div class="avatar-placeholder">
  <img src="profile.jpg" alt="プロフィール写真" style="width: 100%; height: 100%; object-fit: cover;">
</div>
```

### 2. 自己紹介文やスキルの変更
`index.html` を開いて、変更したい文字を検索して書き換えるだけです。
- `<h1 class="hero-title">`: トップのお名前やキャッチコピー
- `<section id="about">`: 自己紹介文、基本情報、強み
- `<section id="skills">`: スキルの追加・削除（`<span class="skill-tag">新しいスキル</span>` を増やすだけ）
- `<section id="works">`: 制作物や担当したプロジェクトの紹介
- `<section id="contact">`: SNSリンク（XやGitHubのURLを自身のアカウントに変更）

### 3. テーマカラーの変更
`style.css` の先頭にあるカラー変数を変えるだけで、サイト全体のアクセントカラーを一括変更できます：
```css
:root {
  --primary: #4f46e5; /* メインカラー（現在はインディゴブルー） */
  --secondary: #06b6d4; /* サブカラー（現在はシアン） */
}
```

## 🌐 インターネットに公開したいときは？

完成したウェブサイトは、以下のような無料サービスを使うことで、世界中の誰もが見られるURL（例: `https://your-name.github.io`）として簡単に無料公開できます：
- **GitHub Pages**: GitHubにコードをアップロードするだけで即公開（エンジニアに大人気）
- **Vercel / Netlify**: フォルダをドラッグ＆ドロップするだけで数秒で公開可能
- **Cloudflare Pages**: 高速で無料枠が充実

公開手順など、さらに進めたいことがあればいつでも質問してください！
